# SLT Gestão — página de apresentação

Sistema de gestão para assistência técnica: ordens de serviço, clientes,
produtos, cobrança e análise do negócio. Windows, com aplicativo Android
que usa os mesmos dados.

**Página:** https://mikerock12.github.io/slt-gestao-demo/

## O que tem aqui

Só a apresentação: uma página HTML e as imagens das telas. Este repositório
**não contém o código-fonte** do SLT Gestão, nem banco de dados, nem
configuração, nem qualquer dado de cliente. As telas mostradas usam uma base
inventada — nomes, telefones e valores de mentira.

```
index.html      a página
assets/         imagens das telas
```

## O produto

- Ordem de serviço com orçamento e recibo em PDF, enviados pelo WhatsApp.
- Cadastro de clientes com histórico, e catálogo de peças com margem.
- Cobrança parcelada ou que se repete, semanal, quinzenal ou mensal.
- Análise do negócio: panorama em sete janelas de tempo, gráfico de velas e
  projeção de 7, 15 e 30 dias.
- Ditado por voz transcrito **no próprio aparelho** — o áudio não é enviado
  para servidor nenhum.
- Funciona sem internet. A nuvem é opcional, e serve para levar os mesmos
  dados ao celular.
